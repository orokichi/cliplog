# ClipLog

スクリーンショットや画像をドラッグ＆ドロップ／貼り付けで取り込み、フレームと装飾をカスタマイズして、スタイリッシュな記録（ログ）として保存・管理できるWebアプリ。Liquid Glass UI、モーションは [Kinetics](https://kinetics.colorion.co/) のスプリング表現を参照。

## 機能
- D&D（画面のどこにでも）、`Ctrl+V` / `Cmd+V` 貼り付け、複数ファイル選択
- PNG / JPEG / WebP / GIF / HEIC（HEICはブラウザ内で変換）
- フレーム：なし・macOS・ブラウザ・スマホ・ポラロイド・ガラス
- 背景グラデーション12種＋カスタム色・透明、比率（自動/1:1/4:5/16:9/9:16）
- 余白・角丸・影・傾き・拡大、キャプション・日付スタンプ・ノイズ・ダーク枠
- PNG書き出し（1x/2x/3x）、クリップボードコピー
- ライブラリ：IndexedDBに保存、検索・タグ絞り込み・並べ替え・再編集・削除

## ショートカット
`⌘/Ctrl+V` 貼り付け · `⌘/Ctrl+S` 保存 · `/` ライブラリ検索 · `↑↓` 取り込み画像の切替 · `Esc` 閉じる

ビルド不要の静的サイト（index.html / style.css / app.js）。
